# Asset list and capture

**Trigger:** the script is approved.

## Steps
1. List every visual the script needs, in script order: screen captures, logos, proof shots and b-roll.
2. Capture web pages with the key sentence highlighted.
3. Build a contact sheet.

## Done when
Every asset exists or is marked missing.

## Approval
Post the result in its own thread and move the card to review. Nothing leaves the business without the owner's `approve`.

The Kanban board is named in your AGENTS.md. Read canon/ before any public-facing work.

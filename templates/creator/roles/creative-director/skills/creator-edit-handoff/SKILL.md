# Editor handoff

**Trigger:** filming is done (never before).

## Steps
1. Build the edit folder: <slug>/{handoff,incoming,review,outputs}.
2. Write a cut sheet in script order with real filenames and hold times, labelled as a starting point.
3. Put footage, the cut sheet and assets in handoff/. Never the script, private notes or source data.

## Done when
Every filename in the cut sheet exists.

## Approval
Post the result in its own thread and move the card to review. Nothing leaves the business without the owner's `approve`.

The Kanban board is named in your AGENTS.md. Read canon/ before any public-facing work.
